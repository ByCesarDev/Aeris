## Referenced Projects / Proyectos de Referencia

- **[RenderDragonShaderLoader](https://github.com/honeymirror/RenderDragonShaderLoader)**: LGPL-3.0.
  Referenced for shader pack discovery, material hook concepts, window drag-and-drop, and UI layout patterns.
- **[Lamium](https://github.com/amatouhake/Lamium)**: LGPL-3.0.
  Referenced for LeviLamina SDK packaging (`levilamina-client-sdk.lua`), custom-drawn placeholder scene management, and client input handling.
- **[Iris Shaders](https://github.com/IrisShaders/Iris)**: LGPL-3.0.
  Inspiration for the shader pack management experience, Iris-style slider interaction, and parameter layout hierarchy. No visual assets or code bundled.
- **[BetterRenderDragon](https://github.com/QYCottage/BetterRenderDragon)**: AGPL-3.0.
  Referenced for material hot reload memory signature concepts. Not bundled or redistributed.
- **[OptiFine](https://optifine.net/)**: Proprietary software.
  Referenced solely for `shaders.properties` convention and `shaderpacks/` directory structure. No OptiFine code or assets are included.
